# Changelog

## [v5.4.0] - 2026-09-05
### Added
- Daily User Convenience Suite: `orvpass cp <name>`, `orvpass cpu <name>`, `orvpass cpt <name>`.
- Single-line instant add `orvpass quick-add <title> <user> <pass>`.
- Browser URL launcher `orvpass open <name>` and TUI hotkey `o`.
- Fast Star favorite toggle `orvpass fav toggle` and TUI hotkey `s`.
- Shell auto-alias generator `eval "$(orvpass init-shell)"`.
- Credential cloning (`orvpass duplicate`) and instant renaming (`orvpass rename`).
- Enter-key quick-copy-and-quit in TUI dashboard.

## [v5.3.0] - 2026-09-05

- Complete Import & Export support for 20+ formats.
