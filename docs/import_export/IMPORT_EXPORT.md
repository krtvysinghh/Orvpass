
# Orvpass Import Export


## Supported Import

- Bitwarden
- 1Password
- KeePass
- LastPass
- Dashlane
- Proton Pass
- RoboForm
- CSV
- JSON


## Supported Export

- Orvpass JSON
- CSV
- Bitwarden compatible
- KeePass compatible


## Rules

- Never upload data
- Offline conversion
- Validate before import
- Preserve folders
- Preserve notes
- Preserve TOTP
